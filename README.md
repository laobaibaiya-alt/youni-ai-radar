- `data/`：不含第三方 README 原文和内部分析元数据的 JSON 快照

## 你会看到什么

每天从公开 GitHub 项目中筛选值得关注的 AI、Agent、开源模型和开发工具，
并为每个项目整理“项目是什么、主要目的、适合谁使用、为什么值得关注”四项中文解释。

“雷达评分”是本项目根据 AI 相关性、增长、新颖性、近期活跃度和 Trending
信号计算的筛选分，不是 GitHub 官方排名，也不构成对项目质量或安全性的背书。

本仓库是公开阅读版，只包含日报和脱敏数据。采集引擎、内部状态、第三方
README 证据和本机运行信息不在公开范围。
